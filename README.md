# AI 旅行工具箱（ai-travel-kit）

讓 AI 助理（Claude、ChatGPT、Gemini…）先**訪談你**，幫你建一份**屬於你自己的旅行總檔**，
之後每一趟旅行的**出發前、旅途中、回來後**，都從這份總檔出發幫你。

這不是一份「必帶清單」。通用清單網路上到處都有；這個工具箱想做的是：
AI 知道你通常晚多久出門、爬山多快、跟誰去、最怕什麼、上次差點出什麼事，排出來的行程才會真的適合你。
每趟回來再把實際的數字和教訓寫回去，下一趟就更準。

## 怎麼用（不用安裝任何東西）

打開你常用的 AI（網頁版或 App 都可以），貼上這句：

```
請讀 https://github.com/drpwchen/ai-travel-kit 的 START.md，照裡面的說明幫我。
```

AI 會問你現在在哪一步：

| 你在 | AI 會做 |
|---|---|
| 第一次用 | 問你幾個問題（快速版約 5 分鐘），產出你的「我的旅行總檔」；想更準可以再回答完整版 |
| 規劃一趟旅行 | 依你的出發日列「這週該做的事」、整理同行者的偏好、查證景點 |
| 快出發了 | 個人化行李清單、證件保險檢查、網路用量估算、機場功課 |
| 旅途中 | 每晚陪你排隔天：天氣、班次、用你自己的速度排時間 |
| 出事了 | 延誤、取消、行李沒到、生病：一次告訴你下一步做什麼 |
| 回來了 | 理賠、花費分攤、檢討，然後**更新你的總檔** |

產出的總檔請**存起來**（AI 會依你用的平台告訴你怎麼存最方便）。下次出國，把網址跟你的總檔一起給 AI 就好。

### AI 打不開網址時

有些 AI 不能讀網頁。打開 [`ALL-IN-ONE.md`](ALL-IN-ONE.md)（全部內容合成一個檔），整份複製貼給它，或下載後上傳。

### 用 Claude Code 或 Codex

```
git clone https://github.com/drpwchen/ai-travel-kit
```

在資料夾裡開 Claude Code／Codex，說「幫我建旅行總檔」。你的總檔會存在 `my/`，這個資料夾不會被 git 追蹤。

## 隱私

- 工具箱**不會**問你護照號、訂位代號、保單號、卡號這類資料，也請你不要貼給 AI。總檔只記「哪裡找得到」。
- 你的總檔寫了你和同行者的習慣、健康限制，**請存在你自己的地方，不要公開**。
- `examples/` 裡的範例都是**虛構的**模擬資料。

## 裡面有什麼

| 檔案 | 內容 |
|---|---|
| [`START.md`](START.md) | 給 AI 的工作說明：判斷階段、規則、怎麼保存總檔 |
| [`interview.md`](interview.md) | 訪談題庫（快速版 5 題＋完整版），每題寫了「回答會改變什麼」 |
| [`templates/`](templates/) | 「我的旅行總檔」與「旅行檢討」的格式 |
| [`phases/`](phases/) | 規劃、出發前、旅途中、回來後，各階段 AI 要做的事 |
| [`guide/`](guide/) | 時間軸、預設估計值、行李清單、天氣與穿著、突發狀況與理賠、查詢工具、全家行程網頁、出國開會 |
| [`examples/`](examples/) | 虛構的完成範例：一份總檔、一份檢討 |
| [`ALL-IN-ONE.md`](ALL-IN-ONE.md) | 以上全部合成一個檔（給不能讀網址的 AI） |

內容以從台灣出發的旅客為主，用繁體中文寫；AI 會用你的語言回答。

## 來源

整理自作者十幾年自助旅行的筆記，以及一趟帶長輩的北歐自駕家庭旅行（全程跟 AI agent 一起規劃、排每日行程、處理延誤理賠）。
個人資料與實際數字都已移除，換成通用的估計值與虛構範例。

旅行相關的規定（簽證、入境系統、航空公司規定、保險條款）常常在變，
**AI 給你的建議請以官方來源為準**；工具箱已經要求 AI 查證並標日期，但最後請自己確認。
