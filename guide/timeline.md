# 時間軸：出發前半年到回國後

> 給 AI：用使用者的出發日把每一段換算成**實際日期**，只列「現在這段」該做的。
> 標 🔄 的是會變的規定，每次都要用官方來源重查並標日期。

## 最重要的十條（每趟都適用）

1. **一定要有每日行程表**（含日期與星期）。沒有它最容易記錯離開日期、錯過預約。
2. **機票用附旅遊不便險的信用卡刷全額**（沒有這種卡就跳過），另外再買旅遊平安險＋不便險；**越早保越好**（颱風警報、罷工預告發布後才保通常不賠）。
3. **出發前一個月查所有人的證件效期**：護照、本國駕照、國外開車要的證件（多數國家是國際駕照；**日本要的是駕照日文譯本**，不是國際駕照 🔄）。
4. **託運行李放追蹤器、隨身包放 1–2 天換洗**：行李晚到很常見，而且回程那段的行李延誤，很多保險不賠。
5. **至少一支手機有能打電話的門號**；同行者的網路錯開不同電信。
6. **信用卡要有實體卡＋PIN**：日常可以全靠手機支付，但加油機、停車機、租車押金還是要實體卡。刷卡或提款時問要不要用台幣計價，**一律選當地貨幣**（台幣計價＝動態貨幣轉換 DCC，匯率差常多付 3–5%，海外手續費照收；拒絕後機器常會再問一次）。
7. **用自己的實測速度排行程**，不用網路上的建議時間（`guide/baselines.md`）。
8. **有硬截止的事從截止時間倒推**（托運截止、還車關門、末班船），再多留 30 分鐘。
9. **班次查官方來源，當天出發前再查一次即時資訊**；官網上的 PDF 時刻表可能是舊的。
10. **出事時每筆花費拍收據、記「誰付／哪張卡／幾人份」**，自己買替代機票前先停下來問保險（`guide/emergencies.md`）。

## 出發前 6–3 個月

不到 3 個月才開始規劃：這段沒做的全部挪到本週，依期限排序。

- [ ] 定目的地、日期、誰去。日期看櫻花、紅葉、極光、雪季這類自然現象的：預測常在出發前 1–3 個月才公布 → 住宿先訂可免費取消，「預測公布日」和「免費取消期限」一起放行事曆，機票等日期大致定了再刷或選可改期的票。開會的話：盯早鳥與講者報名期限、取消政策（`guide/conference.md`）。
- [ ] **所有人的護照**：沒有或已過期（小時候辦的通常過期）→ 現在就辦；有效的查回程日起 ≥6 個月，快到期現在就換。台灣役男（19 歲起未服役）出境要先上役政署系統申請核准（🔄）。
- [ ] **機票**：附險的卡刷全額；刷之前確認卡附的險保到哪些人（同行父母常不算）。機票訂好就決定要不要另買不便險。兩段不同訂位代號的轉機，風險自己扛，轉機至少留 3–4 小時；第一次入境某區（例：申根）要算入境排隊時間。廉價航空票價常不含託運與選位，比價要加回去，隨身行李限重常約 7 kg 而且會秤（🔄）。公司買的機票，個人卡附險通常不適用（`guide/conference.md`）。==去程沒搭到要在起飛前通知航空公司==，否則回程常被自動取消（no-show 條款）。
- [ ] **住宿**：熱門城市、旅館少的小地方要早訂；免費取消期限記**原文、原始時區、換算後的台灣時間**（時區或夏令時間不確定就標待確認、提早處理）；住超過 5 天找有洗衣機的；有飲食限制優先有廚房；含晚餐的旅館晚餐常是固定時段，當天行程要倒推。訂房後收到「付款失敗、請重新驗證卡片」的訊息（email、WhatsApp、甚至訂房 App 內），就算姓名與訂單都對也不點，回 App 查訂單或直接打給旅館（旅館帳號被盜的案例 2026 仍很多）。
- [ ] **租車**：每位駕駛的證件效期；至少兩位駕駛登記在租約；另買的車損險被保人＝實際主駕；跨國開車要有租車公司書面許可。
- [ ] **熱門門票開賣日**（常見 7–60 天前開賣；**有些熱門館、名作、熱門餐廳提前數月就滿**，逐一查官網）→ 換算成日期放進行事曆。
- [ ] 定日期前查**出發地與目的地的連假**（機票住宿變貴、店家公休）。

## 出發前 1 個月

- [ ] **保險**（還沒保的現在保；已保的確認細節）：看投保起點（抓到機場報到時間）、延誤怎麼賠（定額還是實支）、旅程更改、行李延誤、海外醫療（含搜救後送）。
      目的地有外交部紅色旅遊警示時，旅平險常不承保（橙色可能降額）。
      有的保險只能本人投保 → 約好一天大家一起保。每人的保單確認信集中到主辦。
- [ ] **要用的卡就緒**：開海外交易、綁手機支付、記得 PIN；要用卡進機場貴賓室的話，現在辦還來得及。
      要在國外提款：台灣的金融卡要先開通跨國提款，並在台灣 ATM 設一組 4 位數的國外提款密碼（國外 ATM 多半只收 4 位數，多數銀行預設關閉）。
- [ ] **網路**：見 `phases/before.md` §3。長輩沒用過 eSIM，要有人幫忙裝。
- [ ] 🔄 **當地法規地雷**：電子菸、處方藥、酒類販售時段與宗教節日禁酒、無人機。
- [ ] 🔄 **入境規定**：簽證、電子旅行許可、入境登記、新上路的出入境系統（例：歐洲申根區的 EES 已上路、ETIAS 2026-10 查仍未啟用；英國 ETA）。查官方來源、寫查詢日期。
      - **轉機地也要查**：有些地方不出機場也要證件（例：在美國轉機要 ESTA；經中國大陸機場轉機要台胞證）。
      - **免簽或豁免有到期日的**（例：韓國對台灣的 K-ETA 豁免 2026-10 查只到 2026-12-31），確認涵蓋旅行日期。
      - ==只從政府官方網站或官方 App 申請==：搜尋結果最上面常是收好幾倍費用的代辦或假網站。
- [ ] 多人同行：開共用行李清單（誰帶什麼）、要不要做行程網頁（`guide/trip-website.md`）。==清單一個月前就要給大家==，大家才有時間買。
- [ ] 團員超過兩人：講好走散怎麼辦、互開位置分享。

## 出發前 2 週

- [ ] **長輩或行動不便**：機場輪椅與行動協助通常免費，但要提早向航空公司申請（歐盟規定至少起飛前 48 小時），可以一路送到轉機的登機門。
- [ ] **特殊餐**（通常出發前 24–48 小時截止，去回每一段都要選）。素食代碼常見：VLML 奶蛋素、VGML 全素、AVML 印度素、VOML 東方素（不含蔥蒜）。🔄 各航空公司定義不同：代碼只是起點，不保證成分，嚴格飲食限制或過敏要向航空公司確認，並自備替代食物。
- [ ] 罷工查詢（航空、機場鐵路），48 小時前再查一次。
- [ ] 藥：處方藥自備；共用成藥包統計人數與數量。
- [ ] 外交部出國登錄（台灣：領事事務局）。
- [ ] 離線地圖（山區、偏遠地區一定要）、當地交通 app、天氣 app。
- [ ] 列印包：官方英文版訂單 PDF（機票、住宿、租車、保險英文證明、會議邀請函）＋每日行程表，一份紙本（到了才發現訂單出錯時，紙本確認信最快解決）。
- [ ] 要送禮的話列清單。

## 出發前 5 天

- [ ] **先打包一次**（`guide/packing.md`）。
- [ ] 託運每件放追蹤器；隨身包放 1–2 天換洗、藥、充電線。
- [ ] 每個人手機裡找得到自己的電子機票、保單、緊急電話。

## 出發前 48–24 小時

- [ ] **線上報到**；登機證加進手機錢包，一支手機也可以存全團的當備援。國內線那段也要報到；廉價航空沒線上報到，機場報到常要另外收費（🔄）。
- [ ] **電子入境卡**：很多國家只在抵達前約 72 小時內開放填寫（例：泰國、馬來西亞、韓國 🔄），官方的免費。
- [ ] 選位：先講清楚目標（例：靠走道的兩人座、看得到山的那一側），再看機型座位圖。
- [ ] 航班時間以最新通知為準（航空公司會改時間，電子機票上可能是舊的）。
- [ ] 查好機場（`phases/before.md` §5）。

## 旅途中

- 每晚照 `phases/during.md`。
- 照片當天上傳共享相簿。
- 群組裡收到的重要檔案馬上存到手機（有些通訊軟體的檔案幾天後會過期）。

## 回國後

- [ ] 出事的話：保險通常要求事故後幾天內通知（`guide/emergencies.md` §3）。
- [ ] 公務出國的核銷期限（`guide/conference.md`）。
- [ ] 花費、檢討、更新總檔（`phases/after.md`）。
