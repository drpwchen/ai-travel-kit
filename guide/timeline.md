# 時間軸：出發前半年到回國後

> 給 AI：用使用者的出發日把每一段換算成**實際日期**，只列「現在這段」該做的。
> 標 🔄 的是會變的規定，每次都要用官方來源重查並標日期。

## 最重要的十條（每趟都適用）

1. **一定要有每日行程表**（含日期與星期）。沒有它最容易記錯離開日期、錯過預約。
2. **機票用附旅遊不便險的信用卡刷全額**（沒有這種卡就跳過），另外再買旅遊平安險＋不便險；**越早保越好**（颱風警報、罷工預告發布後才保通常不賠）。
3. **出發前一個月查所有人的證件效期**：護照、國際駕照、本國駕照。
4. **託運行李放追蹤器、隨身包放 1–2 天換洗**：行李晚到很常見，而且回程那段的行李延誤，很多保險不賠。
5. **至少一支手機有能打電話的門號**；同行者的網路錯開不同電信。
6. **信用卡要有實體卡＋PIN**：日常可以全靠手機支付，但加油機、停車機、租車押金還是要實體卡。
7. **用自己的實測速度排行程**，不用網路上的建議時間（`guide/baselines.md`）。
8. **有硬截止的事從截止時間倒推**（托運截止、還車關門、末班船），再多留 30 分鐘。
9. **班次查官方來源，當天出發前再查一次即時資訊**；官網上的 PDF 時刻表可能是舊的。
10. **出事時每筆花費拍收據、記「誰付／哪張卡／幾人份」**，自己買替代機票前先停下來問保險（`guide/emergencies.md`）。

## 出發前 6–3 個月

不到 3 個月才開始規劃：這段沒做的全部挪到本週，依期限排序。

- [ ] 定目的地、日期、誰去。日期看櫻花、紅葉、極光這類自然現象的：住宿先訂可免費取消，預測出來再定。開會的話：盯早鳥與講者報名期限、取消政策（`guide/conference.md`）。
- [ ] **所有人的護照**：沒有或已過期（小時候辦的通常過期）→ 現在就辦；有效的查回程日起 ≥6 個月，快到期現在就換。
- [ ] **機票**：附險的卡刷全額；刷之前確認卡附的險保到哪些人（同行父母常不算）。機票訂好就決定要不要另買不便險。兩段不同訂位代號的轉機，風險自己扛，轉機至少留 3–4 小時；第一次入境某區（例：申根）要算入境排隊時間。
- [ ] **住宿**：熱門城市、旅館少的小地方要早訂；免費取消期限寫進行事曆（換算台灣時間）；住超過 5 天排一次洗衣；有飲食限制優先有廚房。
- [ ] **租車**：每位駕駛的證件效期；至少兩位駕駛登記在租約；另買的車損險被保人＝實際主駕；跨國開車要有租車公司書面許可。
- [ ] **熱門門票開賣日**（常見 7–60 天前開賣；**有些熱門館、名作、熱門餐廳提前數月就滿**，逐一查官網）→ 換算成日期放進行事曆。
- [ ] 定日期前查**出發地與目的地的連假**（機票住宿變貴、店家公休）。

## 出發前 1 個月

- [ ] **保險**（還沒保的現在保；已保的確認細節）：看投保起點（抓到機場報到時間）、延誤怎麼賠（定額還是實支）、旅程更改、行李延誤、海外醫療（含搜救後送）。
      有的保險只能本人投保 → 約好一天大家一起保。每人的保單確認信集中到主辦。
- [ ] **要用的卡就緒**：開海外交易、綁手機支付、記得 PIN；要用卡進機場貴賓室的話，現在辦還來得及。
- [ ] **網路**：見 `phases/before.md` §3。長輩沒用過 eSIM，要有人幫忙裝。
- [ ] 🔄 **當地法規地雷**：電子菸、處方藥、酒類販售時段、無人機。
- [ ] 🔄 **入境規定**：簽證、電子旅行許可、入境登記、新上路的出入境系統（例：歐洲申根區的 EES 出入境系統、ETIAS 電子旅行許可）。查官方來源、寫查詢日期。
- [ ] 多人同行：開共用行李清單（誰帶什麼）、要不要做行程網頁（`guide/trip-website.md`）。==清單一個月前就要給大家==，大家才有時間買。
- [ ] 團員超過兩人：講好走散怎麼辦、互開位置分享。

## 出發前 2 週

- [ ] **特殊餐**（通常出發前 24–48 小時截止，去回每一段都要選）。素食代碼常見：VLML 奶蛋素、VGML 全素、AVML 印度素、VOML 東方素（不含蔥蒜）。🔄 各航空公司不同。
- [ ] 罷工查詢（航空、機場鐵路），48 小時前再查一次。
- [ ] 藥：處方藥自備；共用成藥包統計人數與數量。
- [ ] 外交部出國登錄（台灣：領事事務局）。
- [ ] 離線地圖（山區、偏遠地區一定要）、當地交通 app、天氣 app。
- [ ] 列印包：官方英文版訂單 PDF（機票、住宿、租車、保險英文證明、會議邀請函）＋每日行程表。
- [ ] 要送禮的話列清單。

## 出發前 5 天

- [ ] **先打包一次**（`guide/packing.md`）。
- [ ] 託運每件放追蹤器；隨身包放 1–2 天換洗、藥、充電線。
- [ ] 每個人手機裡找得到自己的電子機票、保單、緊急電話。

## 出發前 48–24 小時

- [ ] **線上報到**；登機證加進手機錢包，一支手機也可以存全團的當備援。國內線那段也要報到。
- [ ] 選位：先講清楚目標，再看機型座位圖。
- [ ] 航班時間以最新通知為準（航空公司會改時間，電子機票上可能是舊的）。
- [ ] 查好機場（`phases/before.md` §5）。

## 旅途中

- 每晚照 `phases/during.md`。
- 照片當天上傳共享相簿。
- 群組裡收到的重要檔案馬上存到手機（有些通訊軟體的檔案幾天後會過期）。

## 回國後

- [ ] 出事的話：保險通常要求事故後幾天內通知（`guide/emergencies.md` §3）。
- [ ] 公務出國的核銷期限（`guide/conference.md`）。
- [ ] 花費、檢討、更新總檔（`phases/after.md`）。
